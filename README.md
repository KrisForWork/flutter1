# ТестВик (проект `test1`)

Простое Flutter-приложение: **один экран** без скролла и переходов.

Тема экрана — «Типы тестирования»: заголовок, краткое описание, список типов и подвал с ФИО.

## Запуск

```bash
flutter pub get
flutter run
```

## Структура

```text
lib/
  main.dart   # точка входа
  app.dart    # DirectoryApp + единственный экран
assets/images/
  profile.png
  article_*.png
```

## Экран (сверху вниз)

1. Полоса на всю ширину — название приложения «ТестВик» по центру  
2. Прямоугольник с боковыми отступами — тема «Типы тестирования»  
3. Прямоугольник — краткое описание термина  
4. Строка: картинка + прямоугольник со списком типов (без пояснений)  
5. Внизу — фото и ФИО / группа  

Дерево виджетов:

```text
DirectoryApp
└─ MaterialApp
   └─ _HomePage
      └─ Scaffold
         └─ Column
            ├─ полоса заголовка
            ├─ блок темы
            ├─ блок описания
            ├─ Row (картинка + список типов)
            ├─ Spacer
            └─ подвал (фото + ФИО)
```
