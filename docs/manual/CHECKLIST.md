# Чек-лист ручного тестирования — «Справочник»

**Приложение:** учебный справочник записей  
**Платформы:** Windows / Android / Web (по наличию)  
**Приоритеты:** P0 — smoke, P1 — core, P2 — edge  

Легенда результата: `PASS` / `FAIL` / `BLOCKED` / `N/A`

---

## P0 — Smoke

| ID | Действие | Ожидаемый результат | Результат |
|----|----------|---------------------|-----------|
| S1 | Запустить приложение | Открывается экран «Справочник», без краша | |
| S2 | Проверить демо-данные | Видны записи: Unit-тест, Widget-тест, Чек-лист, Нагрузочное тестирование | |
| S3 | Проверить счётчик | Текст вида «Показано: 4 · Всего: 4 · Избранных: 1» | |
| S4 | Открыть «Добавить» (FAB или кнопка) | Экран «Новая запись» с полями названия, описания, категории | |
| S5 | Открыть экран «Нагрузка» (иконка спидометра) | Экран «Нагрузка» с выбором N и кнопками | |

---

## P1 — Список и фильтры

| ID | Given / When / Then | Результат |
|----|---------------------|-----------|
| F1 | **Given** демо-данные. **When** ввод в поиск `unit`. **Then** остаётся «Unit-тест», счётчик «Показано: 1» | |
| F2 | **Given** демо. **When** поиск `UNIT` (верхний регистр). **Then** та же одна запись | |
| F3 | **Given** демо. **When** чип «Только избранные». **Then** виден только «Чек-лист» | |
| F4 | **Given** демо. **When** категория «Flutter». **Then** только «Widget-тест» | |
| F5 | **Given** демо. **When** категория «Тестирование». **Then** «Unit-тест» и «Чек-лист» | |
| F6 | **Given** демо. **When** «Тестирование» + «Только избранные». **Then** только «Чек-лист» | |
| F7 | **Given** активные фильтры. **When** чип «Все» + снять избранные + очистить поиск. **Then** снова 4 записи | |
| F8 | **Given** поиск без совпадений (`zzz`). **Then** «Нет записей», «Показано: 0» | |

## P1 — Детали / избранное / удаление

| ID | Действие | Ожидаемый результат | Результат |
|----|----------|---------------------|-----------|
| D1 | Тап по записи в списке | Экран «Детали записи» с названием, категорией, описанием | |
| D2 | На деталях — звезда (избранное) | Текст «В избранном», звезда активна; в списке счётчик избранных растёт | |
| D3 | Повторно звезда | «Не в избранном» | |

| D5 | Удалить на деталях | Возврат к списку, запись исчезла, «Всего» уменьшился | |

## P1 — Экран «Нагрузка»

| ID | Действие | Ожидаемый результат | Результат |
|----|----------|---------------------|-----------|
| L1 | Выбрать N=100 → «Сгенерировать» | «Сейчас в справочнике» увеличился на 100; результат с временем в мс | |
| L2 | «Применить фильтр к большому списку» | В «Результат» строка «Фильтр по …» и время | |
| L3 | «Очистить справочник» | 0 записей; на главном — «Нет записей» после возврата | |
| L4 | (по желанию) N=1000 / 10000 | Генерация завершается, UI остаётся отзывчивым насколько возможно | |
